# Diego Cerro · CV

Currículum en HTML y CSS, publicado en https://diegocerro.github.io/CV/

## Archivos

- `index.html`, `styles.css`: la web.
- `cv-print.html`: versión para imprimir, de la que sale el PDF.
- `Diego-Cerro-CV.pdf`: el CV en PDF.

## Regenerar el PDF

Abrir `cv-print.html` en Chrome y usar Imprimir → Guardar como PDF (A4, sin márgenes,
sin encabezados ni pies de página).

## Publicación

GitHub Pages desde la rama `main`, carpeta raíz. Cada push a `main` actualiza la web.
